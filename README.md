# attrition-analysis using Machine Learning and Power BI
A comprehensive Attrition Analysis project featuring predictive modeling (SVM, Neural Network, XGBoost, Random Forest, Decision Trees) and interactive visualizations via Power BI.
This project explores employee attrition through predictive modeling and visual storytelling. It combines data science and business intelligence to understand the key factors influencing attrition and predict the likelihood of employees leaving an organization.
## Key Features

- **Power BI Dashboard**  
  Interactive dashboard to visualize attrition trends.

- **Machine Learning Models**  
  Implemented in a Jupyter Notebook:
  - Support Vector Machine (SVM)
  - Neural Network (MLPClassifier)
  - XGBoost Classifier
  - Random Forest Classifier
  - Decision Tree Classifier

- **EDA & Visualizations**  
  - Correlation heatmaps
  - Bar plots & distribution charts
  - Feature importance analysis

- **Predictive Analysis**  
  Model evaluation using accuracy, precision, recall, and confusion matrix.

## Files Included

- `EA_combined.ipynb` – Jupyter notebook with full EDA, model training, evaluation, and visualizations.
- `Attrition_Dashboard.pbix` – Power BI file with visual dashboard representation of attrition insights.

# To run the Jupyter Notebook:
- Clone this repository
- Create a virtual environment
- Install required libraries (pip install pandas numpy matplotlib seaborn scikit-learn xgboost)
- Launch the notebook
# To view the dashboard:
- Open the .pbix file in Power BI Desktop.
